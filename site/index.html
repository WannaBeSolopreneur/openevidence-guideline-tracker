The problem

Guidance changes fast. A boxed warning, a CDC report, or an FDA notice can land in the middle of a busy clinic week. The update sits in a label or a federal document, and a doctor can miss it.

What this does

A daily pipeline pulls public updates, keeps the link to the original document, and codes a change to a condition or a drug only when a phrase map or a public drug code says so. The tiles use example targets I set for this demo.

    How it's built

    Public sources go into a raw cache. dbt builds staging, intermediate, and mart tables. The export writes JSON for this page. A GitHub Action runs the same path every day.

    Path

    openFDA labels, openFDA recalls, Federal Register, CDC MMWR. Then raw cache. Then dbt staging, intermediate, and marts. Then JSON. Then this page.

    Models

      Metrics

      • median_hours_to_surface, on the last 7 days

      Status

      On track starts at 95 percent of the target. At risk starts at 80 percent. A pace goal uses the share of the week that has passed. Hours to surface is lower is better, so the same bands run the other way.

      Left out

      USPSTF needs an API key, so it is not in this tracker. The old CDC MMWR RSS file stops in 2018, so MMWR rows come from the live CDC media collection as JSON.
